## Minimal tool stack

### Keep / use now
- GitHub
- Python / Flask
- Three.js / WebGL
- Vercel or Render (pick one per deployment)
- PostHog for product analytics when traffic exists
- Datadog only when real observability needs justify it
- Apollo for targeted outbound
- Semrush for SEO / market visibility
- Firecrawl or Tavily for web research (avoid paying for overlapping tools)
- Context7 for current development docs

### Connect only when needed
- Clay — enrichment / prospecting after an offer and lead list exist
- Supermetrics — only when there are live marketing accounts worth aggregating
- Amplitude — only if PostHog is insufficient
- Webflow / Lovable / Floot — use when they materially accelerate a specific client or portfolio build

### Avoid duplicate spend
Do not pay for several tools that solve the same layer:
- multiple hosting providers,
- multiple product-analytics platforms,
- multiple web-research providers,
- multiple CRM/prospecting tools,
- multiple AI site builders.

## 30-day execution system

### Week 1 — proof
- clean the strongest public repo,
- publish one reliable Market Observatory demo,
- publish one polished 3D/WebGL demo,
- collect 3–5 screenshots for portfolio use,
- verify tests and deployment.

### Week 2 — positioning
- update GitHub profile/readme,
- update Indeed/Upwork wording around verified capabilities,
- publish 2 case studies,
- publish a simple service page,
- keep one clear CTA.

### Week 3 — outreach
- build a 30-account prospect list,
- send 5 personalized messages per weekday,
- lead with a small paid pilot rather than a large proposal,
- track response, reply, call, proposal, and close rates.

### Week 4 — conversion
- refine the offer based on objections,
- turn the first completed task into a case study,
- raise pricing only after proof,
- package repeated work into a reusable template/service.

## Core rule

**Service first. Product second.**

Use real client work to discover what should become a reusable product. Do not spend heavily on ads, SaaS, or plugin subscriptions before a working offer has produced real demand.

## Buyer requirements

Ask for: goal, existing repo/stack, API documentation URL, required endpoints/actions, expected input/output, deadline, and whether they already have their own API credentials. Never ask buyers to paste production secrets into Fiverr chat; use placeholder values during development and tell them where to configure secrets securely.

## Reusable gig description

Need a clean API integration or dashboard without exposing credentials in the browser? I can connect documented REST APIs to Python/Flask projects, build reusable client modules, add clear error handling, and provide setup documentation so you can maintain the result after delivery.

Before ordering, send the API documentation and a short description of the result you want. I will confirm scope before implementation. I do not promise investment returns, bypass platform security, or provide access to services you are not authorized to use.

## FAQ

**Can you work with my existing GitHub project?** Yes, if you provide authorized repository access or source files.

**Will you need my API key?** Usually no. I can build with placeholders or a development credential you control. Production secrets should stay in your environment or secret manager.

**Can you deploy it?** I can prepare deployment configuration and, when the account is yours and authorized, help deploy to a supported host.

**Do you build trading bots?** The recommended offer is research/data tooling and integrations, not promises of profitable automated trading.

# Product packages

Sellable artifacts derived from work in this repository.

- `3d-configurator-template/` — the portfolio configurator (`portfolio/3d/`) rebranded as a
  licensable template. Copy, branding, pricing and the call to action are hoisted into a
  single `CONFIG` block so a buyer never edits the renderer. Ships with a buyer-facing
  README, a licence, and Shopify/Webflow embed examples.

Build the distributable zip with:

    cd products && zip -r 3d-product-configurator.zip 3d-configurator-template

The zip is not committed — it is regenerable output.
